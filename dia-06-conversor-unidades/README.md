# Día 6/30 — Conversor de unidades

## Descripción

Aplicación desarrollada con React que permite convertir diferentes unidades de medida de forma dinámica, mediante inputs y selectores.

## Funcionalidades

- Conversión de longitud: kilómetros, metros, centímetros, milímetros y millas.
- Conversión de peso: kilogramos, gramos, miligramos y libras.
- Conversión de temperatura: Celsius, Fahrenheit y Kelvin.
- Intercambio de unidades de origen y destino.
- Actualización automática de los resultados.
- Control de valores vacíos.
- Interfaz responsive con CSS.

## Tecnologías

- React
- JavaScript
- CSS
- Vite

## Conceptos aprendidos

- Gestión de estado con `useState`.
- Inputs controlados y eventos `onChange`.
- Renderizado de listas mediante `map()`.
- Uso de objetos para organizar datos.
- Condicionales y funciones.
- Operaciones matemáticas y conversión de unidades.
- Componentes y estilos responsive.

## Instalación y ejecución

```bash
npm install
npm run dev
```

## Objetivo

Practicar la gestión de estados, los eventos y los cálculos dinámicos en React mediante un proyecto interactivo.
