# Día 7/30 — Quiz de preguntas con React

## Descripción

Aplicación web desarrollada con React que permite responder preguntas tipo test, comprobar las respuestas y obtener una puntuación final.

## Funcionalidades

- Mostrar preguntas con cuatro opciones de respuesta.
- Indicar el progreso de las preguntas.
- Seleccionar una respuesta para cada pregunta.
- Comprobar si la respuesta es correcta o incorrecta.
- Resaltar las respuestas correctas e incorrectas mediante colores.
- Evitar responder varias veces a una misma pregunta.
- Mostrar mensajes de feedback después de responder.
- Calcular y mostrar la puntuación final.
- Mostrar un mensaje según el resultado obtenido.
- Reiniciar el quiz para volver a jugar.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- HTML
- CSS
- JSX

## Conceptos aprendidos

- Gestión de múltiples estados con `useState`.
- Manejo de eventos mediante `onClick`.
- Renderizado de listas utilizando `map()`.
- Uso de objetos y arrays para almacenar preguntas y respuestas.
- Renderizado condicional mediante operadores ternarios y `&&`.
- Uso de índices para acceder a elementos de un array.
- Actualización de estados según las acciones del usuario.
- Aplicación de clases CSS dinámicas.
- Creación de funciones para gestionar la lógica del quiz.
- Control del flujo de la aplicación mediante condiciones.

## Instalación y ejecución

```bash
npm install
npm run dev
```

## Objetivo

Aprender a gestionar varios estados, trabajar con arrays y objetos, utilizar el renderizado condicional y crear una aplicación interactiva en React que actualice su interfaz según las respuestas del usuario.
