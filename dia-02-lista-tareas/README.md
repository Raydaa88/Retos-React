# Día 2/30 — Lista de tareas con React

## Descripción

Aplicación web desarrollada con React que permite gestionar una lista de tareas de forma interactiva.

## Funcionalidades

- Añadir tareas mediante un botón o pulsando Enter.
- Eliminar tareas de la lista.
- Marcar tareas como completadas mediante casillas de verificación.
- Mostrar un mensaje cuando la lista está vacía.
- Mostrar el número total de tareas.
- Impedir que se añadan tareas vacías.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- HTML
- CSS

## Conceptos aprendidos

- Gestión del estado con `useState`.
- Renderizado dinámico de listas con `map()`.
- Filtrado de elementos con `filter()`.
- Actualización inmutable de objetos y arrays.
- Manejo de eventos con `onClick`, `onChange` y `onKeyDown`.
- Renderizado condicional en React.
- Uso de `map()` y del operador spread (`...`) para actualizar elementos de una lista.

## Instalación y ejecución

```bash
npm install
npm run dev
```

## Objetivo

Aprender a gestionar listas y estados en React mediante una aplicación práctica e interactiva.
