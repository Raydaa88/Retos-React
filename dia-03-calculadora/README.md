# Día 3/30 — Calculadora con React

## Descripción

Aplicación web desarrollada con React que permite realizar operaciones matemáticas básicas entre dos números.

## Funcionalidades

- Introducir dos números mediante campos de entrada.
- Realizar sumas.
- Realizar restas.
- Realizar multiplicaciones.
- Realizar divisiones.
- Mostrar el resultado en pantalla.
- Controlar la división entre cero mediante un mensaje de error.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- HTML
- CSS

## Conceptos aprendidos

- Gestión del estado con `useState`.
- Creación de inputs controlados mediante `value` y `onChange`.
- Manejo de eventos con `onClick`.
- Conversión de valores de texto a números con `Number()`.
- Creación de funciones para realizar operaciones matemáticas.
- Uso de condicionales para controlar errores.
- Renderizado dinámico de resultados.

## Instalación y ejecución

```bash
npm install
npm run dev
```

## Objetivo

Aprender a gestionar estados, manejar eventos y actualizar la interfaz dinámicamente en React mediante una calculadora interactiva.
