# Día 5/30 — Generador de contraseñas 🔐

## 📌 Descripción

Aplicación desarrollada con React que permite generar contraseñas aleatorias y personalizadas según las preferencias del usuario.

El usuario puede seleccionar los tipos de caracteres que quiere utilizar, elegir la longitud de la contraseña y copiar el resultado al portapapeles.

## 🚀 Funcionalidades

- Generación de contraseñas aleatorias.
- Selección de la longitud de la contraseña, entre 8 y 32 caracteres.
- Opción de incluir letras mayúsculas.
- Opción de incluir letras minúsculas.
- Opción de incluir números.
- Opción de incluir caracteres especiales.
- Copia de la contraseña al portapapeles.
- Validación para evitar generar contraseñas sin caracteres seleccionados.

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- CSS
- Vite

## 📚 Conceptos de React aprendidos

- `useState` para gestionar el estado de la aplicación.
- Eventos `onClick` y `onChange`.
- Renderizado de datos mediante JSX.
- Uso de checkbox controlados.
- Actualización del estado mediante funciones setter.
- Uso de condiciones `if`.
- Generación de caracteres aleatorios con `Math.random()` y `Math.floor()`.
- Bucles `for` para construir cadenas.
- Uso de la Clipboard API para copiar texto al portapapeles.

## ▶️ Instalación y ejecución

Clona el repositorio y accede a la carpeta del proyecto:

```bash
git clone URL_DEL_REPOSITORIO
cd dia5-password-generator
npm install
npm run dev
```

Abre en el navegador la dirección local que indique Vite.

Practicar los fundamentos de React mediante una aplicación interactiva, trabajando con estados, eventos, condiciones, bucles y manipulación de cadenas.
