# 🚀 30 Days of React

Reto personal de 30 días desarrollando 30 proyectos con **React**, con el objetivo de aprender a crear aplicaciones web modernas, mejorar mis habilidades de programación y construir un portfolio de proyectos.

## 🎯 Objetivo

Durante 30 días desarrollaré un proyecto diario, aumentando progresivamente la dificultad y aplicando los conocimientos adquiridos en cada etapa.

No se trata únicamente de terminar proyectos, sino de comprender cómo funcionan, escribir código por mi cuenta y aprender a resolver problemas reales de desarrollo.

## 🛠️ Tecnologías

- **React** — Desarrollo de interfaces mediante componentes.
- **JavaScript (ES6+)** — Lógica y funcionalidad.
- **HTML5** — Estructura.
- **CSS3** — Diseño y estilos.
- **Vite** — Entorno de desarrollo.
- **Git y GitHub** — Control de versiones y documentación.
- **APIs y otras herramientas** — Se incorporarán progresivamente según las necesidades de cada proyecto.

## ⚙️ Instalación y ejecución

Cada proyecto tiene sus propias dependencias y puede ejecutarse de forma independiente.

1. Clona el repositorio:

   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. Entra en el proyecto que quieras ejecutar:

   ```bash
   cd React30Dias/dia-01-contador
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Arranca el servidor de desarrollo:

   ```bash
   npm run dev
   ```

   Abre en el navegador la dirección local que muestre Vite.
